# Contributing to MetroMate

Thank you for helping improve MetroMate materials.

## Contribution standards

- Keep client information confidential and remove personal data from examples.
- Use accurate, measurable language for marketing claims.
- Follow Instagram, Facebook, and other platform terms when writing workflows.
- Do not submit automation that enables spam, inauthentic engagement, mass-reporting, credential collection, harassment, or evasion of platform safeguards.
- Prefer accessible, clear documentation that clients can follow.

For substantial proposals, open an issue describing the problem, intended audience, and expected outcome before submitting changes.
