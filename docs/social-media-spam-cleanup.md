# Social-media spam and impersonation cleanup

## Purpose

This service supports a client’s legitimate Instagram and Facebook presence by documenting and reporting suspected spam, impersonation, fake profiles, abusive comments, and compromised-account indicators through the platforms’ official reporting and security channels.

## Operating principles

- Work only with documented client authorization.
- Preserve evidence before reporting: profile URL, handle, screenshots, date/time, and the observed behavior.
- Use the platform’s own report, impersonation, copyright, trademark, and account-security processes as applicable.
- Keep a clear client-facing tracker of submitted reports and outcomes.
- Escalate suspected account compromise immediately through official recovery and security procedures.
- Never request passwords, bypass platform controls, automate mass reports, purchase engagement, or target legitimate competitors.

## Workflow

### 1. Intake and authorization

Confirm the client’s owned handles, official domains, brand assets, approved contacts, and scope. Define which categories should be handled: spam comments, fake profiles, impersonation, abusive content, or security alerts.

### 2. Evidence register

Record each case in a tracker:

| Field | Example |
| --- | --- |
| Case ID | MM-IG-001 |
| Platform | Instagram |
| Account or URL | `@example_handle` |
| Category | Suspected impersonation |
| Evidence | Screenshot and profile URL |
| Report route | Official impersonation report |
| Status | Submitted / reviewed / resolved |

### 3. Triage

Prioritize cases involving impersonation, scams, phishing links, threats, leaked information, or suspected compromise. Remove or hide spam comments only where the client has granted valid account access and platform permissions.

### 4. Official reporting

Use the relevant in-platform reporting route. Where a platform asks for ownership proof or rights documentation, obtain it from the authorized client contact and submit it only through the official process.

### 5. Account hardening

Recommend strong unique passwords, two-factor authentication, trusted-admin review, removal of unknown connected apps, recovery-contact checks, and periodic security review.

### 6. Client reporting

Provide a concise report showing reported cases, action date, evidence reference, current status, and next action. Do not guarantee removal: final enforcement decisions are made by the platform.

## Boundaries

MetroMate does not guarantee account removal or manipulate platform enforcement. The service is designed to help clients use legitimate, transparent reporting and account-security practices.
